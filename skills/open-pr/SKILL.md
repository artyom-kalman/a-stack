# Open PR

## Prepare the evidence

Read [pr-presentation](../pr-presentation/SKILL.md) before verification. For
visible changes, capture the resulting state in the running app. Use a short
recording when the action or transition matters. Capture evidence on the
revision being submitted and label fixtures. For nonvisual changes, use
relevant test output, input and output examples, or logs.

## Publish

Confirm the intended repository, base, and task branch. Review the diff against
the base and check for an existing PR. Use the existing PR when it covers the
task. Otherwise open a PR ready for review, or a draft when requested.

Use [pr-presentation](../pr-presentation/SKILL.md) for the title, description,
and attachments. Put evidence beside the behavior it demonstrates and keep
the description current when updating a PR.

Link the PR with the host when supported. Check the published PR for the
expected head and base. Confirm screenshots render and recordings play.
If supporting evidence is missing or an upload fails, state the gap in the
handoff. Return the PR link.
